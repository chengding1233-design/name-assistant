# 名字助手 · Name Assistant

一个把姓名数据打包成数据库的小工具，支持**起名字**、**名字查重**、**上传 Excel 扩充数据**。

- 界面：Vue 3 + Element Plus（移动端友好），本地打包，无需联网。
- 数据：来源于网络收集，仅供参考。
- 页面组件已本地化到 `assets/`，克隆后直接打开 `index.html` 即可用。

## 功能

- 起名字：按姓氏 / 性别/数量生成，并标注「新名字 / 已收录」。
- 名字查重：输入姓名，显示是否收录、出现次数、性别与年龄分布。
- 数据管理：上传 Excel（表头含「姓名 / 年龄 / 性别」）自动合并去重，可导出、可清空。
